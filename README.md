## What I'm building

### [SessionDeck](https://jeremylaederach.ch/en/session-deck/)

An open-source Windows workspace launcher built with .NET 10 and WinUI 3. It starts reusable groups of applications, commands, URLs, and folders while deliberately avoiding unsafe ownership of unrelated processes.

### [Quantified](https://jeremylaederach.ch/en/quantified/)

A personal analytics platform built with Angular, ASP.NET Core, PostgreSQL, and Google Calendar. It brings calendar, finance, coding, health, business, and local system data into focused dashboards and timelines. The product is under active development; its repository remains private while the data and authentication model evolve.

### [Jay-Jay](https://jeremylaederach.ch/en/jay-jay/)

My independent business for websites, hosting, domains, email, and ongoing technical support. Its current systems include bilingual Laravel websites and a separate customer portal for boards, tickets, private documents, requests, and invoices.
